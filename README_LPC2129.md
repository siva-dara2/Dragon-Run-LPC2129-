# 🐉 Dragon Run -- LPC2129 ARM7

A simple dragon-themed game developed using **Embedded C** for the
**LPC2129 ARM7 microcontroller**. This project explores LCD interfacing,
custom character creation, and basic game logic.

## 🎮 About the Project

Dragon Run is a small LCD-based game. The dragon is displayed on the
LCD, and the program controls the game behaviour using Embedded C.

This project was built as a hands-on learning experience to practise
microcontroller programming and bring a simple game to life.

## ✨ Features

-   Dragon-themed LCD game
-   Custom character creation for the LCD
-   Game logic written in Embedded C
-   Runs on the LPC2129 ARM7 microcontroller

## 🛠️ Hardware and Software

### Hardware

-   LPC2129 ARM7 microcontroller / development board
-   Character LCD
-   Required interfacing components and connections

### Software

1.  Clone or download this repository.
2.  Open the project in Keil µVision.
3.  Add the required source and header files to the project.
4.  Select the correct LPC2129 target and project configuration.
5.  Build the project.
6.  Load the generated HEX file into Proteus or program the
    microcontroller board.
7.  Run the simulation or test it on the hardware.

project configuration.*
